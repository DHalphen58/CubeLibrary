# CubeLibrary

A free library of tutorials, algorithms, and videos for official World Cube Association events.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.

GitHub will publish the site at `https://dhalphen58.github.io/CubeLibrary/`.

## Contributing resources

Open a GitHub issue with the official event, resource link, resource type (tutorial, video, or algorithm), and why it is a high-quality free resource. Please respect creator attribution and WCA data terms.

## Scope

This initial version focuses only on official WCA events. Unofficial-event resources and WCA statistics will be added in later releases.
